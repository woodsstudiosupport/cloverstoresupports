# Historical catalogue records

These records are retained for reference and are not part of the published catalogue.

- `previous-app-records/` preserves the individual app records before they were aligned with the published listings.
- `unpublished-apps/` preserves Arcade, Testbuilt and Test records that were not in the published catalogue.
- `registry-placeholder.json` preserves the old unnamed placeholder.
- `reviews.json` preserves the review group for the unpublished Test listing.

Current listings are in the root `registry.json` and matching `apps/` records. Current published reviews are in the root `reviews.json`. Restoring a historical app to publication should be a deliberate reviewed change.
